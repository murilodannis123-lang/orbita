# Órbita

Jogo de foguetes que mistura Spaceflight Simulator e Kerbal Space Program: monte o foguete, decole da base, atravesse as camadas da atmosfera, entre em órbita, vá até a Lua e volte de paraquedas. Física de verdade em escala 1:10.

**Jogar:** https://murilodannis123-lang.github.io/orbita/

## Instalar como aplicativo (sem bordas)
- **Android (Chrome):** abra o link → menu ⋮ → *Adicionar à tela inicial* / *Instalar app*.
- **iPhone (Safari):** abra o link → Compartilhar → *Adicionar à Tela de Início*.

Abre em tela cheia, sem barra do navegador, e funciona offline depois da primeira abertura. Os salvos ficam guardados no próprio aparelho.
